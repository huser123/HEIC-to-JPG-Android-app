# HEIC → JPG V1.0.1

The app now has an English and Hungarian interface. Tap **Language** or
**Nyelv** to switch. The app remembers your choice.

## Install

Download **HEIC-JPG-1.0.1.apk** from the release assets. The signed APK
requires Android 10 or later.

**Uninstall V1.0.0 before installing V1.0.1.** This release uses a new
signing key.

## Verify the download

The APK is 2,080,885 bytes. Compare its SHA-256 hash with the attached
`SHA256SUMS` file.
